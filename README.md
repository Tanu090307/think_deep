# AI Study Companion

An AI-powered study assistant that converts textbooks into
topic-wise summaries, flashcards, and quizzes.

## Core Features
- Textbook upload or selection
- Topic-based content generation
- Exam-focused outputs

## Tech Stack
- Backend: Python, FastAPI
- Frontend: React / Next.js
- Vector DB: FAISS / Chroma
